# Mực & Mèo

Web luyện viết chữ Hán và chăm mèo 3D. Mở GitHub Pages từ nhánh `main`, thư mục `/(root)`. Để xem ở máy tính, mở thư mục bằng máy chủ HTTP tĩnh; không mở `index.html` qua `file://`.

Tiến độ, xu và các bé mèo được lưu trong trình duyệt. Khi chuyển từ link cũ, tải bản sao lưu ở mục **Tiến độ** trên bản cũ rồi nhập vào bản GitHub.

Ảnh sách scan và bản sao lưu cá nhân không nằm trong repo. Trang **Thuyết Hán Tự** vẫn tra được chỉ mục và số trang.
